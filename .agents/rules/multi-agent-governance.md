# Multi-Agent Workspace Governance

## File Ownership & Boundaries
1. **Claude Code Files (Strictly Read-Only for Antigravity)**:
   - `docs/requirements/FUNCTIONAL_REQUIREMENTS.md`: Tracks implemented functional requirements per phase. Antigravity MUST NEVER edit, overwrite, or modify this file.
   - `docs/plans/*`: Phase implementation plans generated by Claude Code. Antigravity MUST NEVER edit, overwrite, or modify any file in `docs/plans/`.
2. **Antigravity Managed Files**:
   - `docs/requirements/high-level-requirements.md`
   - `docs/specs/technical-specs.md`
   - `docs/requirements/phaseN-requirements.md` (individual phase requirement specs)
