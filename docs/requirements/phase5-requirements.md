# Phase 5 Requirements: AIDiscovery Scaffolding and Bucket Processing

## 1. Objective
Implement the foundational structure and workflow for the `AIDiscovery` feature. This phase bridges the output from the Phase 3 Music Preference Aggregator (the buckets) and prepares the pipeline for the actual Gemini AI requests, ensuring the process is properly delayed, sequenced, and paced.

## 2. Asset Relocation
- **Rule**: All prompt templates located in `docs/specs/assets/prompts/*.md` and the language mapping file at `docs/specs/assets/countries-languages.json` MUST be **copied** (not moved) into the `src/` directory.
- **Target Location**: Place them in the appropriate infrastructure folders (e.g., `src/NewAlbumsDiscovery.Infrastructure/Gemini/Prompts` and `src/NewAlbumsDiscovery.Infrastructure/Gemini/Assets` as already partially initiated).

## 3. AIDiscovery Workflow Constraints
The `AIDiscovery` feature acts upon the buckets generated by the Phase 3 Aggregation.

- **Trigger Delay**: The `AIDiscovery` execution MUST start exactly **30 seconds** after the Bucket Aggregation process has successfully finished (e.g., `await Task.Delay(TimeSpan.FromSeconds(30))`).

### 3.1 Design Pattern Mandate
Because the operations within this feature will grow significantly in complexity during subsequent phases (integrating external AI APIs, parsing JSON, managing rate limits, etc.), **monolithic loops are prohibited**. 
- Claude Code MUST utilize robust, extensible design patterns (e.g., **Pipeline**, **Strategy**, or **Observer** patterns) to define the three stages below. Each stage must be isolated into its own handler or service.

### 3.2 Stage 1: Notification of Start
- **Current Behavior**: Simply print the total number of buckets that are about to be processed to the console.
- **Future Context**: This will eventually trigger complex UI or system-level notifications.

### 3.3 Stage 2: Bucket Processing Loop
- **Sorting**: The pipeline must iterate through the buckets arranged in **descending order** based on the count of songs inside each bucket.
- **Current Processing Behavior**: For each bucket, print the bucket name and the count of songs to the console.
- **Pacing Constraint**: After a bucket is processed, the system MUST take a **10-second break** (`await Task.Delay(TimeSpan.FromSeconds(10))`) before starting the next bucket.
- **Future Context**: This stage will eventually execute the two-step Gemini AI Prompt chain (Genre Expansion -> Discovery Query) for each bucket.

### 3.4 Stage 3: Full Report Publication
- **Current Behavior**: Once all buckets have been processed, print the total number of processed buckets to the console to signal completion.
- **Future Context**: This will eventually collate all AI-discovered albums, cross-reference the internal database to remove duplicates, and publish a comprehensive final discovery report.
