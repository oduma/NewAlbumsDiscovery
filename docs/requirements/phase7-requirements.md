# Phase 7 Requirements: AI Discovery Prompt Preparation

## 1. Objective
Refine the `BucketProcessingStage` introduced in Phase 5. In this phase, the application must analyze each bucket generated by the Music Aggregator and prepare the exact Markdown prompts required to query the Gemini API in future phases. 

Instead of executing the API calls, the system will dynamically substitute variables into the templates and print the resulting generated prompts to the console.

## 2. Configuration & Common Variables
The system must dynamically resolve the following global variables for all templates:
- **`{{maxAlbums}}`**: This value must be loaded from `appsettings.json` (e.g., `NewAlbumsDiscovery:AIDiscovery:MaxAlbumsPerQuery`).
- **`{{timeframe}}`**: This value must be calculated dynamically at runtime based on the system's `TimeProvider`. The format MUST be: `"between {today - 30 days} and {today}"` (e.g., `"between 13-JUL-2026 and 13-AUG-2026"`).

## 3. Bucket Processing Logic
For every bucket (in descending order of track count, continuing the pacing rules from Phase 5), the system MUST perform the following:

### 3.1. Standard Action (All Buckets)
- Print the Bucket Name and Number of Tracks to the console. This MUST happen for all buckets, regardless of language or type.

### 3.2. Instrumental Exclusion
- **Condition**: If the Bucket's Language is exactly `"Instrumental"`.
- **Action**: Do **NOT** calculate or print any prompts for this bucket. Instrumental music requires different discovery mechanics which are completely out of scope for this phase.

### 3.3. Prompt Calculation Rules (Non-Instrumental)
Based on the bucket's hierarchy level, render and print the corresponding prompts:

#### Level 1: Country/Region Only
- **Templates**: `country-prompt.md`
- **Substitutions**: Replace `{{country}}` with the bucket's Country. Replace `{{timeframe}}` and `{{maxAlbums}}`.
- **Action**: Print the rendered prompt to the console.

#### Level 2: Country + Language
- **Templates**: `country-language-prompt.md`
- **Substitutions**: Replace `{{country}}` and `{{language}}`. Replace `{{timeframe}}` and `{{maxAlbums}}`.
- **Action**: Print the rendered prompt to the console.

#### Level 3a: Country + Genre (No Specific Language)
- **Prompt 1**: `genre-expansion-prompt.md`
  - Substitutions: Replace `{{genre}}` with the bucket's Genre. Replace `{{country}}`. (If template requires `{{language}}`, substitute the country's default language using `countries-languages.json` or fallback gracefully).
- **Prompt 2**: `country-genres-prompt.md`
  - Substitutions: Replace `{{country}}`. Replace `{{genres}}` with the exact literal string `"TBD"` (this will be handled by API chaining in future phases). Replace `{{timeframe}}` and `{{maxAlbums}}`.
- **Action**: Print both rendered prompts to the console.

#### Level 3b: Country + Language + Genre
- **Prompt 1**: `genre-expansion-prompt.md`
  - Substitutions: Replace `{{genre}}`, `{{country}}`, and `{{language}}`. 
- **Prompt 2**: `country-language-genres-prompt.md`
  - Substitutions: Replace `{{country}}`, `{{language}}`. Replace `{{genres}}` with the exact literal string `"TBD"`. Replace `{{timeframe}}` and `{{maxAlbums}}`.
- **Action**: Print both rendered prompts to the console.

## 4. Output Expectations
After taking the 10-second delay per bucket, the console output for a Level 3b bucket should look like:
```text
Processing Bucket: USA - English - Indie Pop (120 tracks)
--- PROMPT 1: GENRE EXPANSION ---
[Rendered markdown content of genre-expansion-prompt.md here]
--- PROMPT 2: DISCOVERY QUERY ---
[Rendered markdown content of country-language-genres-prompt.md here, with genres replaced by "TBD"]
```
